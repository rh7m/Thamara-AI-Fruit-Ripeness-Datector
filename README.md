## 🌾 Project Overview

Thamara (ثمرة) is an AI-powered agricultural platform designed to help reduce food waste and support farmers in Saudi Arabia. It combines automated fruit classification with a workforce coordination system, helping farmers organize harvesting activities more efficiently.

---

## 🎯 Project Objective

The project aims to improve fruit inspection accuracy using artificial intelligence while connecting farmers with local youth and available workers to provide harvesting assistance when crops reach the appropriate stage of ripeness.

---

## 🔍 How It Works

### 📸 1. Image Input

Farmers capture images of dates or other fruits through the mobile application for automated analysis.

### 🧠 2. AI-Powered Analysis

A custom Convolutional Neural Network (CNN) analyzes visual characteristics, including fruit color and texture, to determine its condition.

### 🍎 3. Fruit Classification

The system classifies each fruit into one of three categories:

- Unripe
- Ripe
- Rotten

### 🤝 4. Smart Workforce Activation

When ripe fruit is detected, the system enables the **Request Workforce** button. This allows farmers to request harvesting assistance and connect with local youth and available workers who can participate in the harvest.
